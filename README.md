# Ramkumar — developer portfolio

Responsive portfolio built with React, TypeScript, Vite, Tailwind CSS and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to any static host.

## Structure

- `src/data/portfolio.ts`: resume-based profile, links, projects, experience, and skills.
- `src/components/`: shared navigation, footer, headings, tags, links, and project illustrations.
- `src/sections/`: hero, projects, about, experience, skills, and contact.
- `src/index.css`: Tailwind theme, shared styles, and custom illustrations.
- `src/assets/`: original downloadable resume.

Raavana Thalaigal uses the supplied actual website screenshot, linked to the live website. Company project previews remain illustrative UI concepts, not screenshots of production applications. Only the public trust project has a live-site link; internal applications show contribution details. Email and phone links use the visitor's installed apps. Copy-email requires clipboard permission. Google Fonts are optional; local fallback fonts work offline.
